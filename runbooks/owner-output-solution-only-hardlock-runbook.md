# Owner Output Solution Only Hardlock Runbook

1. Before owner output, classify the message as SUCCESS, ACTION, or OWNER_ONLY_GATE.
2. If a safe autonomous action exists, perform or route it and use ACTION only if a message is required.
3. Convert routine blockers into same-RUN PackFix or remediation.
4. Use OWNER_ONLY_GATE only for proven irreversible/account/legal/payment/security actions.
5. Use SUCCESS only after implementation evidence, validation evidence, receipt, readback, and no active blocker.
