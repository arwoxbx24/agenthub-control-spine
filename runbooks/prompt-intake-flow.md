# Prompt Intake Flow

1. Normalize task class and scope.
2. Search duplicate YouTrack tasks.
3. Create or reuse one controlling task.
4. Select a bounded prompt/report file path.
5. Update `INDEX.md`.
6. Validate metadata, no secrets, and no raw internal links.
7. Attach evidence to YouTrack.
