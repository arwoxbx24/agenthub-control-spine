# Anti-Fabrication Policy

Do not claim SUCCESS from:

- task creation only;
- wrapper PASS with embedded BLOCKED/PARTIAL;
- sandbox-only proof;
- unauthenticated UI;
- HTTP 200 when the user outcome is not HTTP;
- stale receipts.
