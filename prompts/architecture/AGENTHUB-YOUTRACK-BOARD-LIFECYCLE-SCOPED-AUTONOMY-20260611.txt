# AgentHub YouTrack Board Lifecycle And Scoped Autonomy Contract

Install durable controls so implementation contours are task-bound, YouTrack issues are owned by their creating contour, board stages are advanced by workers, and Done is forbidden until issue stage readback confirms `Done`.

Key controls:
- duplicate search before issue creation;
- full task card with RUN_ID, repository, branch, lane, evidence, blocker state;
- Backlog -> Develop -> Review -> Test -> Done lifecycle enforcement;
- YouTrack command or custom-field transition route with readback;
- same-contour self-healing for missing issue, route, payload, fallback, status, and board mapping blockers;
- scoped permission manifest for YouTrack, GitHub control-spine, and runtime worker lanes;
- Lane 6 destructive proof for any irreversible action;
- final Russian caveman owner output only: `Fact / Action / Left`.
