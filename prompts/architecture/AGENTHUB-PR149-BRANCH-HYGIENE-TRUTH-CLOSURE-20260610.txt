# AgentHub PR149 Branch Hygiene Truth Closure Prompt

## Task Class

Architecture truth-closure prompt for PR `#149`, branch-hygiene cleanup, stale branch deletion claims, default-branch lookup failures, and false Done prevention.

## Mission

Prevent agents from claiming that PR `#149` cleaned old branches, merged, restored runtime, or deleted remote refs when repository evidence says otherwise.

The agent must report the exact truth state:

- remote branch deletions performed: `0`;
- PR `#149` is not merged unless GitHub readback proves it;
- `github_delete_branch_ref` route is waiting for metadata refresh;
- live/server/Hiddify/AgentHub runtime recovery is not restored by this PR;
- default branch lookup failure is not proof that a PR/branch artifact does not exist.
